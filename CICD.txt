What is CI/CD?

CI/CD stands for:

CI (Continuous Integration): Every code change is automatically built and tested.
CD (Continuous Delivery/Deployment): If the build passes, a new version is automatically deployed.

For your project:


Developer
    │
    ▼
Push to GitHub
    │
    ▼
GitHub Actions
    │
 ┌──┴───────────────┐
 │                  │
Run Tests      Build Docker Images
 │                  │
 └──────┬───────────┘
        ▼
 Push Images to Docker Hub
        │
        ▼
 Production VPS
        │
docker compose pull
docker compose up -d

True Continuous Deployment (CD)

A fully automated pipeline looks like this:

Push
   │
   ▼
GitHub Actions
   │
   ├── Tests
   ├── Build
   ├── Push to Docker Hub
   │
   ▼
SSH into EC2
   │
   ├── docker compose pull
   ├── docker compose up -d
   └── docker image prune -f


   Now everything is automatic.
